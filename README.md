### What's inside

- **Yearly bar chart** — total contributions vs. active days, 2021–2026
- **2026 monthly breakdown** — month-by-month bars
- **Contribution heatmap** — five-stop GitHub-style grid, light & dark aware
- **Insight cards** — activity timeline, key metrics, monthly trend

### Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

### Tech

Plain HTML + CSS + a sprinkle of vanilla JS — no build step, no dependencies.
The page picks up your system theme via `prefers-color-scheme`.
