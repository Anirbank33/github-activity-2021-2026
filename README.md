> An automated, zero-dependency telemetry dashboard visualizing developer contributions and engineering velocity from 2021 to 2026. Built with semantic HTML5, modern CSS custom properties, and vanilla JavaScript, it adapts dynamically to the user's OS color scheme (`prefers-color-scheme`).

## 🌐 Live Interactive Dashboard

🔗 **Direct Live Link**: [https://anirbank33.github.io/github-activity-2021-2026/](https://anirbank33.github.io/github-activity-2021-2026/)

---

## 🚀 Key Features

- 📈 **Multi-Year Contribution Velocity (2021–2026)**: Visual comparison of annual total contributions versus active coding days.
- 📅 **Granular Monthly Breakdown**: Month-by-month activity metrics highlighting commit distribution and intensity.
- 🟩 **Responsive Contribution Heatmap**: High-fidelity 5-stop contribution grid adapting to dark and light modes.
- 💡 **Executive Insight Cards**: High-level engineering summaries covering longest active streaks, total repositories touched, and consistency metrics.
- ⚡ **Zero-Dependency Architecture**: 100% vanilla client execution with zero build steps or external bundlers for ultra-fast load times.

---

## 🛠️ Tech Stack & Implementation

- **Frontend**: Semantic HTML5, CSS Custom Properties (Variables), Vanilla JavaScript (ES6+)
- **API Source**: GitHub GraphQL API (`user.contributionsCollection`)
- **Hosting**: GitHub Pages with automated HTTPS enforcement

## 💻 Local Development

Clone and serve locally using Python or any static file server:

```bash
git clone https://github.com/Anirbank33/github-activity-2021-2026.git
cd github-activity-2021-2026

# Serve with Python 3
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
